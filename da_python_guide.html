DataAnnotation Python Assessment

The DataAnnotation (DA) Python Assessment is an open-book, take-home coding challenge designed to test your ability to read unstructured data, write clean Python code, and output a specific result.

Format
Un-proctored, open-book coding assignment
Environment
Local IDE (VS Code / Colab), submit via text box
Libraries
Standard Python (`sys`, `re`, `requests`, `bs4`)

The 2 Most Common Test Problem Patterns

1. Number-Word Decoding (Pyramid)

Pattern A

Given lines containing numbers and words in random order (e.g., 3 love, 1 I, 6 dogs, 2 like).

  • Goal: Sort pairs by numbers, construct pyramid structure (line 1 has 1 number, line 2 has 2, line 3 has 3...).
  • Output: Extract words corresponding to the last number of each pyramid row (1, 3, 6, 10, 15...).

2. 2D Grid / Coordinate ASCII Art

Pattern B

Given structured data containing rows of 3 elements: an X coordinate, a Y coordinate, and a character (like █ or *).

  • Goal: Parse coordinates, dynamically construct a matrix matching max_x + 1 and max_y + 1.
  • Output: Printing grid line-by-line visually spells out large uppercase letters or words.
Pyramid Decoder Reference Implementation (Python 3) 
def decode_message(file_path):
    word_map = {}
    with open(file_path, 'r') as file:
        for line in file:
            parts = line.strip().split()
            if len(parts) == 2:
                word_map[int(parts[0])] = parts[1]

    decoded_words = []
    step = 1
    current_num = 1
    
    # Pyramid end numbers follow formula: 1, 1+2=3, 3+3=6, 6+4=10...
    while current_num in word_map:
        decoded_words.append(word_map[current_num])
        step += 1
        current_num += step

    return " ".join(decoded_words)

Sample Practice Exercise & Key

Task Scenario: Cartesian Grid Decoder

Write a Python function parse_grid_message(data_input: str) -> str that parses a multi-line input string containing 2D coordinate pairs and characters, returning a formatted ASCII grid string.

  • Each line contains: X_coordinate Y_coordinate Character.
  • (0, 0) is at the bottom-left corner (increasing Y moves up).
  • Blank grid spaces must be populated with single spaces ' '.
  • Must return the grid string (rows separated by \n). Do not print to stdout.
Model A Script IndexError / Direct Print 
def parse_grid_message(data_input: str) -> str:
    lines = [line.strip() for line in data_input.strip().split('\n') if line.strip()]
    parsed_data = []
    
    max_x = 0
    max_y = 0
    
    for line in lines:
        parts = line.split()
        x, y, char = int(parts[0]), int(parts[1]), parts[2]
        parsed_data.append((x, y, char))
        if x > max_x: max_x = x
        if y > max_y: max_y = y
        
    # Create grid based on maximum dimensions
    grid = [[' ' for _ in range(max_x)] for _ in range(max_y)]
    
    # Place characters on grid
    for x, y, char in parsed_data:
        grid[y][x] = char
        
    # Output grid string
    for row in grid:
        print("".join(row))
Model B Script Shallow Copy Bug 
def parse_grid_message(data_input: str) -> str:
    lines = [line.strip() for line in data_input.strip().split('\n') if line.strip()]
    if not lines:
        return ""

    parsed_data = []
    for line in lines:
        parts = line.split()
        parsed_data.append((int(parts[0]), int(parts[1]), parts[2]))

    max_x = max(item[0] for item in parsed_data)
    max_y = max(item[1] for item in parsed_data)

    width = max_x + 1
    height = max_y + 1

    # Initialize grid matrix
    grid = [[' '] * width] * height

    # Map coordinates (0,0 at bottom-left)
    for x, y, char in parsed_data:
        row_idx = max_y - y
        grid[row_idx][x] = char

    return "\n".join("".join(row) for row in grid)
Official Answer Key & High-Scoring Rationale Model 
[VERDICT]
Model B is preferred over Model A, but both models contain critical bugs that require correction. Model B follows prompt constraints and correctly maps Cartesian coordinates, whereas Model A fails multiple prompt requirements and raises runtime IndexErrors.

[PROMPT CONSTRAINT & INSTRUCTION FOLLOWING]
- Model A: FAILED. Model A prints the grid directly to stdout instead of returning a string as requested. Additionally, it fails to map (0,0) to the bottom-left corner, placing (0,0) at the top-left instead.
- Model B: FOLLOWED. Model B correctly returns a string formatted with newlines and handles the empty input edge case gracefully.

[MODEL A EVALUATION]
- Execution & Correctness: FAILS with an `IndexError: list assignment index out of range`. It initializes the grid with dimensions `range(max_x)` instead of `max_x + 1`. A coordinate at `(max_x, max_y)` attempts to access an out-of-bounds index.
- Orientation Logic: Incorrect. Placing `grid[y][x] = char` treats (0,0) as top-left.

[MODEL B EVALUATION]
- Execution & Correctness: FAILS logically due to shallow copying during grid initialization (`[[' '] * width] * height`). Multiplying outer list references causes every row to point to the exact same list in memory. Assigning `grid[row_idx][x] = char` mutates column `x` across ALL rows simultaneously.
- Orientation Logic: Correctly calculates row indices via `row_idx = max_y - y`.

[CONCLUSION / REASON FOR PREFERENCE]
Model B is preferred because its overall architecture, coordinate transformation math, and return compliance match requirements. Fixing Model B only requires changing grid initialization to `[[' ' for _ in range(width)] for _ in range(height)]` (deep copy).

Data Structures & Algorithms Scope

What is NOT on the Test

You will NOT be asked to write complex data structures from scratch (Red-Black Trees, Heaps, Graph traversals like BFS/DFS) or heavy algorithmic proofs. Standard computer science LeetCode Hard topics are absent.

1. Practical Data Structures

  • 2D Lists / Matrices
  • Dictionaries & `Counter`
  • Sets & Coordinate Tuples `(x, y)`

2. Algorithmic Logic

  • Cartesian Index Transformation
  • String Parsing & Regex
  • Pyramid & Grid Pattern Decoding

3. LLM Code Review

  • Spotting Shallow Copy Traps
  • Finding Off-By-One Errors
  • Articulating Bug Rationales

Preparation Action Plan

  1. Master 2D Grids: Practice constructing 2D matrices from coordinate tuples and printing line-by-line.
  2. Master String Parsing: Get comfortable using .split(), .strip(), and basic regex.
  3. Prioritize Accuracy: DataAnnotation values strict instruction-following and edge-case handling far more than typing speed.
